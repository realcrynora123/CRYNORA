CRYNORA WEBSITE

Open index.html to see the site. It is a static site: no server or database needed.
Keep index.html together with the img and vid folders.

Quick ways to put it online
1. Netlify Drop: go to app.netlify.com/drop and drag this whole folder onto the page.
2. Cloudflare Pages, Vercel or GitHub Pages: upload the folder as a new project.
3. Any web host (Hostinger, GoDaddy, BigRock): upload everything to the public_html folder.

Then connect your own domain (for example crynora.in) from your host's domain settings.

Things to update before launch: sample prices (search for 'price:' in index.html), order phone/email, shelf life and label claims.
